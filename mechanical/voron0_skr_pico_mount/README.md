# Voron 0 holder for SKR Pico
Holder for BTT Skr Pico, I am not that fond of the cleat style holder as the VHB tape sometimes lets loose dropping the PI, this is a bit more robust.
## Compatibility
* Voron 0 but other 3d printers are probably fine too
## Settings
Recommended slicer settings:
* 0.2mm layer height
* 4 layer walls 1.6mm
* 50% cubic infill
* No supports needed
